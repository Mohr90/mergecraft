# Localization

Mergecraft supports German (`de`) and English (`en`). Language and appearance preferences are independent. A saved language wins over browser/system language preferences; unsupported preferences fall back to English. The selected language is applied to `document.documentElement.lang` and stored under `mergecraft-language` when local storage is available.

## Messages

`src/i18n/messages.ts` contains the English catalog. German messages are the source-language keys, so German remains readable at the call site and no duplicate German catalog needs to be maintained. Translation slots are positional `{{0}}`, `{{1}}`, etc. They can be reordered but must not be added or removed.

- `t('Änderungen')` returns an ordinary translated label. The key is checked by TypeScript.
- `m` is a tagged template for a complete message with opaque interpolation values.
- `h` is a tagged template for UI HTML. It localizes static text and `title`, `aria-label`, `placeholder` and `alt` attributes. It does not translate CSS classes, data attributes, URLs or form values.

The template helper builds and caches a translation plan **before** inserting runtime values. Repository names, paths, commit messages and source code are never scanned for translated words. Values remain opaque, including nested UI HTML. As with the existing renderer, use `esc()` for untrusted text inserted into HTML; `h` escapes translated static text but does not escape runtime HTML fragments for you.

`localizeText()` handles known app-generated backend messages and already displayed app messages. Unmatched raw Git diagnostics remain in their original language. Built-in working-diff labels are explicitly marked for localization; user-supplied revision/branch labels are not.

Dates use `Intl.DateTimeFormat` and `Intl.RelativeTimeFormat`. Counted messages keep the singular/plural forms appropriate to the two supported languages.

## Adding a message

1. Use `t`, `m` or `h` at the UI call site.
2. Add an English entry with the exact normalized German key and matching slots. `npm run typecheck` reports missing template messages.
3. Run `npm run test:browser`, which includes German regressions and English language-switching workflows.

## Adding a language

Extend the language type, detector and catalog selection, add its translated messages, then add an accessible switch button with a native language name. Flags are visual cues rather than the only labels; they do not change Git's locale or choose a repository's region.

## Preserving work

Language changes rerender the current view without reopening the repository or writing to Git. The merge editor restores its existing model, current region, raw text, selection and preview expansion state while keeping its initial snapshot and undo/redo stacks. The language switch is blocked with an explanatory message while a file save is in progress. The comparison view renders its existing pinned revisions without issuing another Git comparison.
